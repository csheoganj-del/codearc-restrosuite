## 💵 Pricing Psychology Tactics

### 1. **Anchor High, Discount Down**
```
❌ Bad: "Starter plan: ₹399/month"
✅ Good: "₹799/month ₹399/month (50% launch discount)"
```

### 2. **Annual Billing Incentive**
```
Monthly: ₹399/mo × 12 = ₹4,788
Annual: ₹3,999 (save ₹799 = 2 months free) ← 60% choose annual
```

### 3. **Make Pro the Default Choice**
```
┌────────────────────────────────────┐
│ Starter │  PRO (MOST POPULAR) 🔥 │ Enterprise │
└────────────────────────────────────┘
```
Center column in 3-tier pricing always gets 50-60% of conversions

### 4. **Remove Friction on Free Tier**
```
❌ Bad: "Start free trial (credit card required)"
✅ Good: "Start for free (no credit card)"
```
Conversion rate: 15% → 35%

### 5. **Social Proof on Pricing Page**
```
"Join 1,247 restaurants already using RestroSuite"
"Rated 4.8/5 by restaurant owners"
"Featured in YourStory, Inc42"
```
