# WhatsApp launch ad — ready to send

## Psychology (why this works)

| Principle | How we use it |
|-----------|----------------|
| **Name / first name** | `{{first}}` — feels 1:1, not a blast |
| **Pain first** | Wi‑Fi drop / billing freeze — owner already feels this |
| **One product story** | Offline bill + kitchen + QR + WA receipts — not a feature dump |
| **Low risk** | Free, no card, minutes — removes “sales call” fear |
| **One CTA** | Single register link |
| **Permission close** | “Ignore if not for you” — reduces spam feel, raises trust |
| **Human sender** | “Team CodeArc” — not “BUY NOW!!!” |

**Avoid:** ALL CAPS, fake urgency, 10 links, “limited seats” lies, heavy image spam every message.

**Image opinion:** Optional. Text-only is safer for bulk + human pacing. Use the image for:
- First ~20 tests / high-value contacts, or  
- Status / story / website  
Not for every of 100+ bulk messages (heavier, more ban risk).
