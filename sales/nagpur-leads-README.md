## How to use the CSV

Columns: `business_name`, `segment`, `area`, `email`, `phone`, `website`, `priority`, `outreach_channel`, `notes`, `status`, `personalized_hook`

Update `status` as you go: `not_contacted` → `emailed` → `whatsapp` → `demo_booked` → `pilot` → `won` / `lost` / `opt_out`.

## Reality check

- Most Nagpur restaurants **do not publish email**. Expect ~20–30% of leads to be email-ready; the rest need **WhatsApp / call / walk-in**.
- Prefer **HIGH** priority multi-outlet and hotel F&B first (Dezzerto, Krishnum, Centre Point, Ashok).
- Do not buy bulk email dumps — bad deliverability and spam risk.
- Expand the list weekly: Google Maps by area (Dharampeth, Civil Lines, Sadar, Manish Nagar, Wardhaman Nagar, Sitabuldi) → website Contact page → Instagram bio.
