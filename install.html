Shared device rules (staff)

  1. Sign out only when another person needs a different account — this clears offline save on purpose
  2. To stay ready overnight: close the tab/app — do not Sign out
  3. Set a Security PIN in Settings for refunds / voids
  4. WhatsApp receipts need the outlet gateway online (green WA / Gateway tray on the office PC)
