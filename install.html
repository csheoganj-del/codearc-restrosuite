Install on every device

Same outlet account works everywhere. Sign in once per device with Keep me signed in for offline and quick reopen.

🖥 Windows PC (counter)

Recommended for main POS / billing PC

  1. Download Setup (installer) or Portable (no install)
  2. If Windows says “Unknown publisher” / SmartScreen: click More info → Run anyway
  3. Sign in with Outlet ID + password, leave Keep me signed in checked
  4. Close the window to tray when needed — don’t Sign out unless switching staff
Download Setup 2.0.4 Portable EXE

Unsigned build (free launch). Code-signing certificate removes SmartScreen later.

📱 Android (kitchen / counter phone)

APK install — works offline after first login

  1. Open this page on the Android device (Chrome)
  2. Tap Download APK
  3. If blocked: Settings → allow install from browser / files
  4. Open RestroSuite → sign in with Keep me signed in
Download Android APK 2.0.4

Not on Play Store yet (side-load). Play listing can be added when you have a Google Play developer account.

🍎 iPhone / iPad

Use Safari PWA (best iOS path without App Store)

  1. Open Safari (not Chrome) → restrosuite.codearc.co.in/login
  2. Tap the Share button
  3. Tap Add to Home Screen → Add
  4. Open the icon → sign in with Keep me signed in
Open login in Safari
Apple does not allow third-party app installs like Android APK. Home Screen web app is the official free path. Native App Store build needs Apple Developer ($99/yr) + separate build pipeline.

🌐 Any browser / Chromebook

No install required

  1. Go to restrosuite.codearc.co.in/login
  2. Sign in with Keep me signed in
  3. Optional: Chrome menu → Install app / Cast for PWA window
  4. Bookmark dashboard for one-tap open
Open web console

Works on Chrome, Edge, Firefox, Safari. Best: Chrome or Edge for PWA install.

Shared device rules (staff)

  1. Sign out only when another person must use a different account — this clears offline save on purpose
  2. To stay ready overnight: close the tab/app — do not Sign out
  3. Set a Security PIN in Settings for refunds/voids
  4. WhatsApp receipts need the outlet gateway online (green WA icon)
